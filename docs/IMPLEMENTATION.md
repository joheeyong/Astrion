## 9. 추천 우선순위 (제안)

스토리 비트와 게임플레이 양쪽을 고려한 단계별 로드맵 (변경 가능):

### 단기 (다음 1~2 작업)
1. **EXP / 레벨업 시스템** — 몬스터 처치 시 EXP 지급, 레벨업 시 스탯 포인트 + MaxHP/MP 증가. 서버 권위 attribution.
2. **채팅 UI 표시** — 채팅 패킷이 이미 송수신되므로, 수신 메시지를 채팅창에 표시.
3. **Act I 막 보스 (Shadow Hulk)** — 잊혀진 숲 깊은 곳에 강한 몬스터 1마리 + 처치 시 다음 단계 잠금 해제.

### 중기 (Act II 도입)
4. **여명의 성채 씬 생성** — 카시오 NPC + 입단 의식 + 도서관 lore.
5. **시리우스 NPC** — 다음 섬에서 첫 만남, 라이벌 사이드 퀘스트.
6. **두 번째 클래스 스킬** — 유성술사의 2번 스킬 (유성 낙하 AoE).

### 장기 (Act III/IV)
7. **2차 전직 시스템** + 클래스별 스킬 풀 확장
8. **상점 / NPC 거래 시스템** + 아틀라스
9. **Act III 비극 콘텐츠** — 안타레스 추적, 시리우스 분기
10. **Act IV 최종 보스 + 결말 분기**
